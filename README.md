# AAM Fleet Registry

This repository holds the published website for AAM Fleet Registry, a live tracker of the aircraft that advanced air mobility companies hold on the FAA registry, the N-numbers they have reserved, and where they have flown.

Live site https://basilbuildsai.github.io/aam-fleet-registry/

The site is rebuilt every night from public FAA and ADS-B data. The source code is private for now.

Built by Basil Yap.
